# 🤖 Memecoin Analyst Bot — بوت محلل عملات الميم

بوت مجاني 100% يراقب عملات الميم الجديدة ويحلّلها ويرسل لك إشارات شراء/بيع على Telegram.

## كيف يعمل؟

```
كل 30 دقيقة (GitHub Actions — مجاني):
  1. 🔍 فحص: أحدث العملات على Dexscreener (BSC / Solana / Base / Ethereum)
     + العملات الرائجة على CoinGecko
     → فلتر صارم: سيولة ≥ $20K + حجم ≥ $10K + 50 صفقة على الأقل (لا ضجيج)
  2. 🛡️ أمان: فحص العقد عبر honeypot.is و RugCheck (كشف النصب والضرائب)
  3. 🗞️ أخبار: 10 مصادر موثوقة بطبقات ثقة (Bloomberg / CNBC / CoinDesk / The Block...)
     → دمج المكرر + تجاهل الضجيج + وزن المعنويات حسب ثقة المصدر
  4. 📊 بيانات مُتحققة: تغير BTC مُقارن بين مصدرين + مؤشر الخوف والطمع
  5. 🧠 الخبير: كلام بسيط — سعر الدخول، أسعار الخروج، نسبة نجاح، والسبب.
     ويتعلّم من نتائج إشاراته السابقة
  6. 📩 تنبيه Telegram بلغة سهلة: ادخل بسعر X / اخرج عند Y
  7. 👁️ متابعة: تنبيه عند كل هدف أو وقف الخسارة + تسجيل النتيجة للتعلم
  8. 📰 ملخص يومي: الصفقات + التحركات + الأخبار + جودة البيانات (صباحاً ومساءً)
  + 📈 مراقبة عملات الميم على Binance لتوقيت الدخول/الخروج
```

## 🧹 تنقية البيانات (data نظيفة)

- **مصادر بطبقات ثقة**: الطبقة 1 = إعلام مالي عالمي (Bloomberg، CNBC)،
  الطبقة 2 = إعلام كريبتو متخصص (CoinDesk، CoinTelegraph، The Block، Decrypt، CryptoSlate)،
  الطبقة 3 = مصادر عامة (للمزاج العام فقط).
- **أخبار العملات**: تُقبل فقط من الطبقتين 1 و2.
- **دمج المكرر**: نفس الخبر من عدة مصادر يُحسب مرة واحدة.
- **التحقق المتبادل**: تغير BTC يُقارن بين CoinGecko وBinance —
  إذا تعارض المصدران لا يُعتمد الرقم.
- **مؤشر الخوف والطمع**: يُخفض نسبة النجاح عند التطرف (خوف أو طمع شديد).
- **فلتر الجودة**: عملات بلا نشاط حقيقي (أقل من 50 صفقة/يوم) تُستبعد تلقائياً.
- **🔄 لائحة الانتظار**: العملات "شبه الجاهزة" (40-59 نقطة) تُعاد فحصها
  كل جولة لمدة 6 ساعات — من تحسّن يُرسل كتنبيه "رجعت بقوة!".
- **⚖️ ضغط الشراء/البيع**: نسبة المشترين مقابل البائعين تؤثر على نسبة النجاح
  (طلب حقيقي +4%، هروب البائعين -6%).
- **🕵️ كشف التداول الوهمي**: حجم أضعاف السيولة بكثير = أرقام مضللة (-8%).
- **🔤 فلتر الرموز**: رفض الحروف الخفية والرموز المُقلّدة لعملات مشهورة (نصب).
- **📣 الترويج المدفوع**: عملات Dexscreener المروّجة تحصل على نقاط إضافية
  (الفريق يستثمر في التسويق = استعداد لحركة سعرية).
- **⏱️ نافذة الفرص**: التنبيهات الجديدة للعملات الأصغر من 48 ساعة فقط.
- **💼 المحفظة الافتراضية**: تجربة وهمية بـ$100 تشري وتبيع تلقائياً حسب الإشارات، وتشوف النتيجة في الملخص اليومي.
- **📉 انزلاق سعري واقعي**: المحفظة الوهمية تحسب 3% انزلاق عند كل تنفيذ (شراء أغلى/بيع أرخص) باش النتائج قريبة من الواقع.
- **⚡ فحص كل 5 دقائق** عبر GitHub Actions (مجاناً للمستودعات العامة).
- **💾 الحالة في cache** GitHub المجاني — بلا آلاف الـcommits، ومزامنة بين الجولات.
- **💰 فحص القيمة السوقية**: FDV ضخم مقابل سيولة صغيرة = خطر إغراق (-8%).
- **🔥 الربط بالرائج**: عملة جديدة رائجة على CoinGecko = اهتمام حقيقي (+5%).
- **🔁 إعادة تقييم الصفقات**: إذا ساءت مؤشرات صفقة مفتوحة يُرسل تحذير خروج مبكر.
- **👀 كشف الضخ المفاجئ**: حجم ساعة ×3 عن المتوسط على Binance = تنبيه مراقبة.

## ⚠️ إخلاء مسؤولية

عملات الميم عالية المخاطر جداً. هذا البوت أداة تحليل مبنية على بيانات عمومية،
وليست نصيحة مالية. لا تخاطر إلا بمبالغ صغيرة تتحمّل خسارتها كاملة.

## ⏱️ الدقة والموثوقية (v3)

- **تشغيل دقيق كل 5 دقائق**: `repository_dispatch` يُفعَّل عبر Webhook من
  [cron-job.org](https://cron-job.org) (مجاني) → `POST /repos/{owner}/{repo}/dispatches`
  مع `{"event_type":"scan"}` — بلا تأخر الـcron تاع GitHub.
  الـ`schedule` كل 15 دقيقة باقي كاحتياطي فقط.
- **الحالة في Gist سري** (`GH_PAT` + `GIST_ID` في Secrets): يعمل كقاعدة بيانات
  NoSQL مجانية — لا يُمسح مثل الـcache. الملف المحلي + cache باقيين كاحتياطي.
- **حماية من الحظر (429)**: كل طلبات HTTP ببصمة متصفح حقيقي + Exponential Backoff
  (إعادة المحاولة بعد 3ث ثم 6ث عند الحظر المؤقت).
- **جولة واحدة في المرة** (`concurrency`): منع تداخل الجولات حمايةً لحالة Gist.

### إعداد cron-job.org (مرة واحدة)
1. أنشئ Token في GitHub: Settings → Developer settings → Personal access tokens
   (classic) بصلاحيتي `repo` و`gist` → احفظه في Secrets باسم `GH_PAT`.
2. أنشئ Gist سري فيه ملف `state.json` بمحتوى `{}` → ضع معرفه في Secrets باسم `GIST_ID`.
3. في cron-job.org: مهمة جديدة كل 5 دقائق → URL:
   `https://api.github.com/repos/sjob7652-byte/crypto-analyst/dispatches`
   → POST → Header: `Authorization: Bearer <GH_PAT>` →
   Body: `{"event_type":"scan"}`.
