# 🤖 Memecoin Analyst Bot — بوت محلل عملات الميم

بوت مجاني 100% يراقب عملات الميم الجديدة ويحلّلها ويرسل لك إشارات شراء/بيع على Telegram.

## كيف يعمل؟

```
كل 30 دقيقة (GitHub Actions — مجاني):
  1. 🔍 فحص: أحدث العملات على Dexscreener (BSC / Solana / Base / Ethereum)
     + العملات الرائجة على CoinGecko
     → فلتر صارم: سيولة ≥ $20K + حجم ≥ $10K + 50 صفقة على الأقل (لا ضجيج)
  2. 🛡️ أمان: فحص العقد عبر honeypot.is و RugCheck (كشف النصب والضرائب)
  3. 🗞️ أخبار: 10 مصادر موثوقة بطبقات ثقة (Bloomberg / CNBC / CoinDesk / The Block...)
     → دمج المكرر + تجاهل الضجيج + وزن المعنويات حسب ثقة المصدر
  4. 📊 بيانات مُتحققة: تغير BTC مُقارن بين مصدرين + مؤشر الخوف والطمع
  5. 🧠 الخبير: كلام بسيط — سعر الدخول، أسعار الخروج، نسبة نجاح، والسبب.
     ويتعلّم من نتائج إشاراته السابقة
  6. 📩 تنبيه Telegram بلغة سهلة: ادخل بسعر X / اخرج عند Y
  7. 👁️ متابعة: تنبيه عند كل هدف أو وقف الخسارة + تسجيل النتيجة للتعلم
  8. 📰 ملخص يومي: الصفقات + التحركات + الأخبار + جودة البيانات (صباحاً ومساءً)
  + 📈 مراقبة عملات الميم على Binance لتوقيت الدخول/الخروج
```

## 🧹 تنقية البيانات (data نظيفة)

- **مصادر بطبقات ثقة**: الطبقة 1 = إعلام مالي عالمي (Bloomberg، CNBC)،
  الطبقة 2 = إعلام كريبتو متخصص (CoinDesk، CoinTelegraph، The Block، Decrypt، CryptoSlate)،
  الطبقة 3 = مصادر عامة (للمزاج العام فقط).
- **أخبار العملات**: تُقبل فقط من الطبقتين 1 و2.
- **دمج المكرر**: نفس الخبر من عدة مصادر يُحسب مرة واحدة.
- **التحقق المتبادل**: تغير BTC يُقارن بين CoinGecko وBinance —
  إذا تعارض المصدران لا يُعتمد الرقم.
- **مؤشر الخوف والطمع**: يُخفض نسبة النجاح عند التطرف (خوف أو طمع شديد).
- **فلتر الجودة**: عملات بلا نشاط حقيقي (أقل من 50 صفقة/يوم) تُستبعد تلقائياً.

## الملفات

| الملف | الدور |
|---|---|
| `main.py` | المشغّل الرئيسي |
| `config.py` | كل الإعدادات والعتبات |
| `clients.py` | الاتصال بمصادر البيانات المجانية |
| `analyzer.py` | محرك التقييم (نتيجة من 100) |
| `alerts.py` | تنسيق رسائل Telegram بالعربية |
| `state.py` | حفظ الصفقات المفتوحة |
| `.github/workflows/scan.yml` | التشغيل التلقائي كل 30 دقيقة |

## الإعداد

اقرأ **[SETUP_AR.md](SETUP_AR.md)** — دليل مصور خطوة بخطوة (10 دقائق).

```bash
pip install -r requirements.txt
python main.py --dry-run
```

## ⚠️ إخلاء مسؤولية

عملات الميم عالية المخاطر جداً. هذا البوت أداة تحليل مبنية على بيانات عمومية،
وليست نصيحة مالية. لا تخاطر إلا بمبالغ صغيرة تتحمّل خسارتها كاملة.
